# Complex Elite Tools Platform

Private Perfex-staff tools at `tools.complexelite.com/hyperframes`, `/ffmpeg`, `/google-maps-scraper`, `/openreply`, `/scrapling`, and `/ai-video-captions`.

The hostname root is a private installed-tools catalogue. Signed-out visitors see the Complex Elite branded sign-in page at `/login`; selecting Continue starts the existing one-time Perfex staff SSO handoff. Tools never asks for or stores Perfex credentials. After authentication the user returns to the Tools catalogue. Each application path is explicit; unknown paths return 404 instead of falling through to another tool.

- HyperFrames is pinned to the official `0.8.226` CLI release, sourced from the [upstream project](https://github.com/heygen-com/hyperframes).
- FFmpeg is compiled from [upstream FFmpeg](https://github.com/FFmpeg/FFmpeg) at commit `aab6cec3e8415154b3f0570f8d131db07a9901de`. The build disables network protocols and provides a static CLI binary.
- `/hyperframes` runs the upstream browser editor (`hyperframes preview`) against a persistent blank composition at `/data/hyperframes/default`. The editor is protected by Perfex staff SSO, including its API, assets, and websocket traffic.
- `/ffmpeg` is a private browser converter for MP4 (MPEG-4/AAC), M4A, FLAC, and WAV, backed by the installed FFmpeg runtime.
- `/google-maps-scraper` proxies the Tools-owned `complexelite/google-maps-scraper` service with its full path preserved. The service's `GOOGLE_MAPS_BASE_URL` is `https://tools.complexelite.com/google-maps-scraper`; pages, HTMX actions, assets, downloads, docs and OpenAPI examples all use this prefix. Old root-level scraper URLs redirect with status 308, preserving methods and queries. The gateway requires a valid Perfex staff session before proxying the app or its API. Docs are at `/google-maps-scraper/api/docs`.
- `/openreply` is a Perfex-gated entry to the Tools-owned OpenReply web, worker, cron, PostgreSQL, and Redis services. The public `/openreply` route rewrites the compiled `/tools/openreply` prefix in upstream paths, text responses, redirects, and cookie paths so the browser URL and generated auth links stay under `/openreply`. Its database was copied from the previous Leads deployment; original database and Redis volumes plus a protected dump remain retained for rollback.
- `/scrapling` is a Perfex-gated connection guide for the Tools-owned Scrapling MCP service. `/scrapling/mcp` forwards to the service's `/mcp` endpoint; the service still validates its own bearer token. Scrapling is an MCP/API service, not a browser UI.
- `/ai-video-captions` proxies the Git-backed Compose deployment from `complexelite/ai-video-captions`. The frontend is attached to the private Dokploy network and the processing backend has no public port.
- No database is needed. HyperFrames project files live on the Dokploy persistent volume mounted at `/data`.
- The browser pages use Perfex's one-time staff SSO handoff. Set `PERFEX_SSO_EXCHANGE_URL` and `STUDIO_SSO_SECRET` in Dokploy; the secret must match the Perfex/Studio integration.
- The conversion form accepts media uploads up to 500 MB, allows one conversion at a time, caps each output at 1 GB and 10 minutes, and deletes temporary files after download or failure. Conversion uses fixed argument lists and does not accept remote URLs or shell input.
- A server-to-server runtime probe is available at `GET /api/v1/runtime/{hyperframes|ffmpeg}`. Authenticate with `X-CE-Timestamp` (Unix seconds) and `X-CE-Signature`, the lowercase hex HMAC-SHA256 of `${timestamp}\nGET\n${path}` using `TOOLS_API_SECRET`. Keep the secret in Dokploy and client server environments only. It returns fixed version/availability information.
- The tools run in a shared runtime container. No arbitrary shell or remote URL processing is exposed. Other apps can use the authenticated conversion endpoint with supported presets; output is returned directly and not retained as a Studio resource.

The app services and routing source are tracked here in `deploy/tools-apps.yml`; secrets remain in `/etc/complexelite/tools-apps.env` on the VPS. Deploy this Swarm stack with `deploy/deploy-tools-apps.sh`. The previous Leads services remain intact for rollback until cutover checks are complete.
